# Dark and Light Theme Toggle

## What will change
- Add a sun/moon toggle to the main navigation on desktop and mobile.
- Use dark mode by default for first-time visitors.
- Remember the visitor’s selection across page changes and future visits.
- Apply the saved theme before the page appears to avoid a light-mode flash.

## Technical details
- Reuse the existing dark-theme color tokens and shared button component.
- Keep the current transparent homepage navigation readable in both themes.
- Verify the default, toggle behavior, saved preference, and mobile layout in the live preview.
